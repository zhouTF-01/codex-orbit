# Codex Orbit

macOS 原生透明桌面悬浮窗，用于查看 Codex 剩余额度、账户重置时间，并提醒本机会话的完成、执行和人工待办状态。

当前版本 **1.0.1**。这是个人制作的非官方工具。

## 安装

当前安装包适用于 **Apple 芯片（M 系列）Mac、macOS 26.0 及以上**。实测环境为 macOS 26.5.1、Codex CLI 0.147.0，其他版本尚未逐一验证。

1. 下载仓库中的 [ZIP 安装包](Codex-Orbit-1.0.1-macos-arm64.zip)，在文件页选择下载。
2. 解压，将 `Codex Orbit.app` 拖入“应用程序”。
3. 确保本机 Codex 桌面应用、Codex CLI 已安装并登录，再打开悬浮窗。

也可以把 ZIP 交给自己的 Codex 自动安装。两种方式的详细步骤与可复制话术见 [INSTALL.md](INSTALL.md)。

安装包使用临时签名，未经过 Apple 公证。当前没有应用内升级，也没有设置开机自动启动。

## 使用

- 拖动空白区域移动；默认双击 Shift 隐藏 / 显示。
- 右上角设置可调整置顶、紧凑模式、透明度和双击快捷键。
- 红灯：有需要人工处理、尚未查看的会话。
- 黄灯：有任务正在进行。
- 绿灯：有已完成、尚未查看的会话。
- 点击圆点打开清单，再逐个进入会话；只展开清单不会清除提醒。查看不等于批准审批或回答问题。
- 红 / 绿灯闪约五秒后常亮，直到对应会话逐个查看；黄灯随任务状态熄灭。边框灯带独立闪约三秒后熄灭，亮度与宽度固定。
- 额度后台每 60 秒刷新。公开加赠消息来自 WhenReset；预测不是官方承诺，个人到账以账户额度为准。

仅监测本机根会话，不包含云主机任务和内部子 Agent。Codex 更新本地协议或数据格式后，可能需要适配。

## 源码与构建

- `Orbit.swift`：AppKit + SwiftUI 界面、额度读取和本机会话监听。
- `build.sh`：本机构建与临时签名。
- `whenreset-cache.json`：用于首次展示的公开消息缓存，按来源时间判断是否过期。
- `PRIVACY.md`：数据读取、存储及联网边界。
- `SHA256SUMS`：已封板安装包校验值。

安装 Xcode Command Line Tools 后，在仓库目录执行：

```sh
zsh build.sh
../'Codex Orbit.app'/Contents/MacOS/CodexOrbit --test
```

默认生成的 App 位于仓库上一级目录；也可以通过 `zsh build.sh /绝对路径/CodexOrbit.app` 指定输出位置。构建脚本复用当前工具链的默认部署目标；不能仅依据 Info.plist 的最低系统声明判断二进制兼容性。本仓库附带的现成安装包实际最低系统为 macOS 26.0。

已有 68 项边界与计时检查通过，覆盖多会话提醒、逐个查看、断线重连、旧读回执和快捷键检测等。物理双击修饰键未由自动化工具代按验证。

## 隐私

安装包没有附带开发者的登录凭据、会话记录或个人文件。运行时在本机读取必要会话数据，未发现上传这些数据或额外持久化的应用代码。公开消息服务仍可看到普通网络访问的 IP 等信息。详见 [PRIVACY.md](PRIVACY.md)。
